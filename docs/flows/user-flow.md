# User Flow

The system should guide small-business users from login to workspace selection, dashboard, setup completion, and daily operations without requiring knowledge of internal app boundaries.

## Primary Flow

1. Authenticate.
2. Select or create workspace/company.
3. Complete setup blockers: subscription, rates/rate sources, DEA seed data, contact/account prerequisites.
4. Use dashboard to enter operational flows: accounting, Girvi, contacts, inventory, sales, purchase, notifications, team management.
5. Return to setup when a workflow detects missing master data.
