# UI Principles

## Product Feel

Rokkad is an operational ERP, not a marketing site. Screens should be dense, predictable, scannable, and focused on daily work.

## Controls

- Use clear buttons for commands.
- Use forms and helper text for setup-heavy data entry such as rates and rate sources.
- Surface setup blockers near the workflow that needs them.
- Keep dashboard metrics readable and consistently formatted.

## Navigation

Navigation should expose required setup paths, especially when a workflow depends on master data such as rates or DEA seed data.
