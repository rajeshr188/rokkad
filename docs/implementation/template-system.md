# Template System

The template migration work consolidated page and partial conventions across the application.

## Direction

- Keep reusable partials small and workflow-specific.
- Avoid duplicating large template blocks across apps.
- Use consistent dashboard, list, form, and detail layouts.
- Preserve HTMX/toast patterns where they improve feedback without hiding server-side behavior.
