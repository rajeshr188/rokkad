# Reconstructed previews for imported opening loans

The owner needs to test the installed ticket templates using imported loans.
These loans have frozen opening evidence but no native approval snapshot or
original issued PDF. Native official ticket issuance must retain its approval
and immutable-artifact requirements.

Add a separate authorized GET preview, using the frozen, reconciled opening
review and checksum-verified accepted import. Preserve the source loan number,
original date, original item principals, rates and collateral facts; do not use
today's rates, outstanding balance or a fabricated approval. Unknown valuations
stay unknown. Customer contact/photo and printed business details use their
current records, explicitly described in the UI. Original collateral photos
without approval evidence remain unavailable.

Reuse current template and paper-profile resolution and preview rendering, with
a mandatory reconstructed/non-official notice on every output page. The standard
PDF is available when no template is assigned. No issue row, artifact upload,
number allocation or financial mutation occurs. Membership/view authorization,
Workspace-scoped lookup, private no-store responses and existing address selection
remain required. Closed archive-only evidence is outside this opening-loan route.

Keep internal migration series codes stable. The new-loan picker displays the
licence number and configured pawn-number prefix, or No prefix for numeric-only
registers; this changes labels, not IDs or counters.
