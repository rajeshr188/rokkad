# Transaction coverage describes the represented financial position

The owner authorizes using accepted available facts without compulsory individual
or bulk book certification. This supersedes origin-based coverage gating in the
3 October transaction-completeness and 5/16 October capture/disclosure decisions.

A supported origination or accepted opening checkpoint and consistent subsequent
canonical transactions establish usable transaction coverage for that represented
position. Unavailable pre-checkpoint receipts remain unavailable. Origin does not
prove missing activity. An explicit unresolved-activity report still makes the
position provisional; unsupported or inconsistent financial evidence stays unknown.

Keep immutable LoanTransactionReview and its exact existing book-assurance meaning.
Missing, aged or changed optional assurance is distinct from an unusable financial
position. Future recording remains an optional declared practice, not a prerequisite
for servicing/monitoring. Existing portable profiles retain their published book
claims; do not reinterpret them as newly certified lifetime cash history.

Use a shared read-only represented-position selector for current monitoring,
evidence disclosures and action prerequisites. Reuse scoped financial inputs within
a calculation. Bump the saved assessment contract so old evidence is not relabelled
as current. Normal worker refresh changes derived projections only.

Borrower communication retains preview/consent/provider/current-risk and send-time
source/date/amount guards. New represented-position intents bind the exact current
position without inventing a review or reviewer. Legacy review-bound intents retain
their original send-time contract. Position-specific deduplication must permit a
new supported amount while rejecting repeated same-position intents. Auction
statutory/custody/settlement guards remain; no new automatic book review is written.

No financial event, agreement, accepted checkpoint, original source or previous
attestation is changed. Application and database changes require coordinated
deployment; this decision alone does not change production.
