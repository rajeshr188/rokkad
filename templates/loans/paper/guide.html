Closing loans: one individual action

Open any supported ordinary loan and choose Close / release loan. Choose current collection and return, or recording a settlement already completed. The loan's origination source does not determine this choice.

Collecting payment now

Review the current settlement and collateral, collect the agreed amount, then confirm full customer handover. For one combined payment covering several loans, use Release multiple loans.

Recording completed settlements

Use the actual settlement date and amount. Select confirmed cash collection and return only when the source establishes them; otherwise retain the unspecified cash/handover basis. Later evidence can confirm handover without collecting again.

Record completed closures groups up to 50 independent loans sharing one actual date. The total is a reconciliation sum, not another collection now. Check each loan's evidence basis, original closing number if supplied, and any authorized interest concession.

Ready selected rows save together or none do. Unselected rows remain on screen. A changed date or activity needs a fresh review. Exact settlement, chronology, permissions, duplicates and custody checks still apply.

Moving away from paper: optional operating commitment

Paper-first recording remains supported. An owner may set a current-recording start date or require an administrator exception for all completed closures. These controls apply equally to individual and bulk recording, with reasons for late discoveries/outages. Earlier loans are not rewritten.

Stored release records, receipts and reversal history remain available. CSV is for book reconciliation; supported loan servicing bundles preserve the connected evidence for portability. Archive claims require their separate admission review.
