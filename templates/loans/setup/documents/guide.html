Loan document layouts: starter guide

A safe first workflow for Owners and Admins.

Back to layouts
The basic workflow: Create draft → preview and test-print → publish → assign → use the normal loan Print button.

1. Create your first layout

  1. Select Create starter layout on the layouts page.
  2. Give it a clear name, such as Main Counter Loan Ticket, and choose the document type.
  3. Use the generated starter definition. Change only the wording, blocks, page settings, and registered bindings you need.
  4. Save the draft, then preview it with a representative loan or event.
  5. Test-print on the actual paper and printer before publishing.

2. Publish and assign it

Publishing freezes a revision. If it later needs correction, clone it to a new draft; published revisions cannot be edited.

Choose the narrowest assignment that matches the business need:

  • Workspace: default for all licenses and series.
  • License: overrides the workspace default for one license.
  • Series: overrides both for one series.

Resolution order: Series → License → Workspace → built-in fixed PDF.

3. Print during normal loan work

Staff continue using the existing Print/PDF actions on the loan, repayment, release, auction, and renewal screens. Loans automatically resolves the applicable published layout. The first official issue is stored exactly; later reprints return those same stored PDF bytes even if assignments change.

Logos, backgrounds, QR, and copies

  • Add PNG/JPEG logos or backgrounds, or a valid bounded PDF background, to a draft revision and reference its asset key in the definition.
  • Use the registered document.verification_id binding for the official QR code.
  • Copy modes support single, original/duplicate, and original/duplicate duplex output. Duplex also requires back-page blocks.
  • Only registered blocks and bindings are allowed; HTML, Python, model paths, and template code are rejected.

Moving or correcting a design

Correction: clone the published revision, edit and test the new draft, publish it, then replace the assignment. Retire the old revision only after confirming the new assignment.

Move between workspaces: export a sanitized pack, import it into the destination, then review, preview, publish, and assign it there. Imports are always unassigned drafts.

If a print fails

  1. Open Integrity diagnostics.
  2. Clone and correct a defective published revision; do not alter stored issue files.
  3. For an urgent recovery print, an Owner/Admin can add ?renderer=fixed to the normal PDF URL. This action is audited.
  4. Before production use, physically test A4/A5, simplex/duplex, long names and tables, regional text, backgrounds, margins, signatures, and QR scanning.
